Documentation

Complete guide to Umbra — everything the app can do, in English.

Introduction

Umbra is a desktop file-hiding manager for Windows. It doesn’t encrypt — it toggles the native NTFS attributes Hidden and optionally System. That makes it instant, reversible, and compatible with Explorer, while Super Hide stays invisible even when “Show hidden files” is enabled.

Self-contained single-file exe. No .NET runtime, no installer, Windows 7+.

Installation

Download the matching exe from Releases:

  • Umbra-win-x64.exe (~68 MB) — recommended for Windows 10/11 64-bit
  • Umbra-win-x86.exe (~63 MB) — universal, works on both 32 and 64-bit

Just double-click to run. No setup. The list is saved next to the exe as items.json.

Quick start

  1. Add files: File / Folder or drag & drop from Explorer.
  2. Select items (Ctrl+Click for multi-select, Ctrl+A for all).
  3. Click Hide or Strong (Super Hide). Use Show to unhide.
  4. Remove from list (Delete) does not delete the file — it only removes the entry.

Hide / Super Hide / Show

Standard Hide

Sets FileAttributes.Hidden. Hidden files disappear when Explorer has “Don’t show hidden files”.

Super Hide (Strong)

Sets Hidden + System. Windows hides System files even when “Show hidden files” is on, unless “Hide protected OS files” is disabled — so this is the truly invisible mode. Umbra asks for confirmation before applying it.

Show

Clears both Hidden and System.

Protected paths blocked: drive roots (C:\), Windows, System32, SysWOW64, Program Files etc. cannot be hidden or scanned — this prevents bricking the OS.

Scan

Scan lets you pick a folder and Umbra walks it recursively to find already-hidden files/folders and import them. Details:

  • Skips reparse points / junctions / symlinks (prevents infinite loops).
  • Limited to 2000 found items and 10k visited directories per scan.
  • Handles UnauthorizedAccessException gracefully and skips protected folders.
  • Critical system roots are blocked.

Search & Statistics

The top stats cards show:

  • Items — total count
  • Hidden — how many are currently hidden
  • Total Size — sum of file sizes (folders count as 0)

Search filters live by file name or parent path (max 200 chars). The settings panel repeats these stats with counts.

Settings panel

Click the gear (⚙) to slide the panel:

  • Shortcuts — reference for all hotkeys.
  • Statistics — Total / Hidden / Visible.
  • Actions — Select All, Clear All (with confirmation), Export List.
  • Tips — multi-select, Super Hide explanation, drag & drop, scan usage.
  • Save & Load — list auto-saved to items.json.
  • Language — English / فارسی toggle (v1.2+ defaults to English).
  • About — logo, tagline, version 1.0, method Hidden+System, .NET 8 WPF, “Made with ♥”.

Save / Load / Export

items.json

Stored next to the exe. Validated on load: max 5 MB and 5000 items, each path canonicalized, invalid / duplicate / reparse-point entries skipped. Save is atomic (tmp → move) to avoid corruption.

Export

Creates Umbra_list_yyyyMMdd_HHmmss.txt on Desktop with lines like [H] C:\path. Filename sanitized, path validated to stay under Desktop.

Security hardening

  • Memory leak fixed: FileItem implements IDisposable and unsubscribes from LanguageChanged.
  • Path validation: blocks device paths (\\?\, \\.\), ADS (file:stream), null bytes, invalid chars, over-long paths, and critical system paths.
  • TOCTOU mitigation: re-canonicalize before SetAttributes, skip reparse points.
  • DoS limits: scan, item count, JSON size, search query length (200), toast length (300).
  • Info disclosure: no stack trace in UI; error log capped at 2 MB and stored in %LocalAppData%\Umbra\Umbra_error.log.

Build from source

dotnet build -c Release
# Self-contained single-file (no prerequisites)
dotnet publish -c Release -r win-x64 -o publish/win-x64
dotnet publish -c Release -r win-x86 -o publish/win-x86

AppHidder.csproj already sets PublishSingleFile, PublishSelfContained, IncludeNativeLibrariesForSelfExtract, EnableCompressionInSingleFile. No extra flags needed.

FAQ

Does Super Hide encrypt?

No. It only sets attributes. Anyone with “Show protected OS files” can still see them.

Will it work without .NET?

Yes. The published exe is self-contained and runs on Windows 7+ with no install.

Can I hide C:\Windows?

Blocked. Umbra refuses critical system paths to avoid breaking Windows.

Where is the log?

%LocalAppData%\Umbra\Umbra_error.log (rotated at 2 MB).
