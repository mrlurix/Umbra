Introduction

Umbra is a desktop file-hiding manager for Windows. It doesn’t encrypt — it toggles native NTFS attributes Hidden and optionally System. Instant, reversible, compatible with Explorer, while Super Hide stays invisible even when “Show hidden files” is enabled.

Self-contained single-file exe. No .NET runtime, no installer, Windows 7+.

Hide / Super Hide / Show

Standard Hide

Sets FileAttributes.Hidden. Disappears when Explorer has “Don’t show hidden files”.

Super Hide (Strong)

Sets Hidden + System. Windows hides System files even with “Show hidden files” on, unless “Hide protected OS files” is disabled — truly invisible. Umbra asks for confirmation.

Show

Clears both Hidden and System.

Protected paths blocked: drive roots (C:\), Windows, System32, SysWOW64, Program Files etc. cannot be hidden or scanned.

Scan

Scan picks a folder and walks it recursively to find already-hidden items:

  • Skips reparse points / junctions / symlinks (prevents loops)
  • Limited to 2000 found items and 10k visited dirs
  • Handles UnauthorizedAccessException and skips protected folders
  • Critical system roots blocked

Search & Statistics

Top stats cards show Items, Hidden, Total Size (folders 0). Search filters live by name or parent path (max 200 chars). Settings panel repeats stats.

Settings panel

Click gear (⚙) to slide panel:

  • Shortcuts — hotkey reference
  • Statistics — Total / Hidden / Visible
  • Actions — Select All, Clear All (confirm), Export List
  • Tips — multi-select, Super Hide, drag & drop, scan
  • Save & Load — auto-saved to items.json
  • Language — English / فارسی toggle (v1.2+ defaults to English)
  • About — logo, tagline, version, method, .NET 8 WPF

Save / Load / Export

items.json

Next to the exe. Validated: max 5 MB and 5000 items, canonicalized, invalid/duplicate/reparse skipped. Save is atomic (tmp → move).

Export

Creates Umbra_list_yyyyMMdd_HHmmss.txt on Desktop with [H] C:\path. Filename sanitized, path validated under Desktop.

Security hardening

  • FileItem implements IDisposable and unsubscribes
  • Path validation: blocks device paths, ADS, null bytes, invalid chars, long paths, critical system paths
  • TOCTOU: re-canonicalize before SetAttributes, skip reparse points
  • DoS limits: scan, item count, JSON size, search query (200), toast (300)
  • Info disclosure: no stack trace in UI; log capped at 2 MB in %LocalAppData%\Umbra

Build from source

dotnet build -c Release
# self-contained single-file
dotnet publish -c Release -r win-x64 -o publish/win-x64
dotnet publish -c Release -r win-x86 -o publish/win-x86

AppHidder.csproj already sets PublishSingleFile, PublishSelfContained, IncludeNativeLibrariesForSelfExtract, EnableCompressionInSingleFile.

FAQ

Does Super Hide encrypt?

No. Only attributes. Anyone with “Show protected OS files” can see them.

Will it work without .NET?

Yes. Self-contained, Windows 7+ no install.

Can I hide C:\Windows?

Blocked. Umbra refuses critical system paths.

Where is the log?

%LocalAppData%\Umbra\Umbra_error.log (rotated at 2 MB).
