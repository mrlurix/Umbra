Everything you need to stay hidden

Built with WPF + .NET 8. Dark neon theme, smooth animations, secure by design.

🙈

Hide & Unhide

Toggle the Hidden attribute instantly. Works for files and folders, even on network drives.

🔒

Super Hide

Hidden + System attributes. Bypasses Explorer’s “Show hidden files” — truly invisible.

🔍

Scan hidden files

Recursively scans any folder for already-hidden items and imports them safely (reparse points skipped).

🔎

Search & multi-select

Fast live search, Ctrl+Click multi-select, Select All, and keyboard shortcuts.

💾

Auto save / export

List auto-saved to items.json (5 MB / 5000 items limit). Export to Desktop as text.

🎨

Modern UI

Dark theme (#0A0A0A), neon accents, animations, statistics and toast feedback.

⬇ Download — Windows 64-bit

For modern Windows 10/11 (x64). Self-contained, ~68 MB compressed. No .NET required.

Download Umbra-win-x64.exe dotnet publish -r win-x64 -o publish/win-x64

⬇ Download — Windows 32-bit

Universal build for old and new PCs (x86). Runs on both 32 & 64-bit, ~63 MB.

Download Umbra-win-x86.exe dotnet publish -r win-x86 -o publish/win-x86
