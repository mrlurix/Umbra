UMBRA Installation

From download to hiding in 10 seconds — no prerequisites.

Requirements

  • Windows 7+ / 10 / 11 (x64 or x86)
  • No extra software — Umbra is self-contained single-file
  • Optional: admin rights only for hiding System-protected folders (normal hide works without)

Download

Grab the latest exe from Releases:

Umbra-win-x64.exe — ~68 MBRecommended for modern Windows 10/11 64-bit Umbra-win-x86.exe — ~63 MBUniversal — works on 32 & 64-bit 
curl -L https://github.com/mrlurix/Umbra/releases/latest/download/Umbra-win-x64.exe -o Umbra.exe
# or for 32-bit
curl -L https://github.com/mrlurix/Umbra/releases/latest/download/Umbra-win-x86.exe -o Umbra.exe
Both are compressed self-contained builds. No .NET install, no installer — just double-click.

Quick start

  1. Double-click Umbra.exe
  2. Add files: File / Folder or drag & drop from Explorer
  3. Select items (Ctrl+Click for multi, Ctrl+A for all)
  4. Click Hide or Strong (Super Hide = Hidden+System)
  5. Use Show to restore

What happens on disk

  • List auto-saved next to exe as items.json (max 5 MB / 5000 items, atomic write)
  • Log (if any) goes to %LocalAppData%\Umbra\Umbra_error.log (2 MB rotated)
  • Hiding sets NTFS attributes — no encryption, instant and reversible

Build from source

dotnet build -c Release
# self-contained single-file
dotnet publish -c Release -r win-x64 -o publish/win-x64
dotnet publish -c Release -r win-x86 -o publish/win-x86
AppHidder.csproj already sets PublishSingleFile, PublishSelfContained, IncludeNativeLibrariesForSelfExtract and EnableCompressionInSingleFile.

Uninstall

Just delete Umbra.exe and items.json. No registry, no services.

del Umbra.exe
del items.json
